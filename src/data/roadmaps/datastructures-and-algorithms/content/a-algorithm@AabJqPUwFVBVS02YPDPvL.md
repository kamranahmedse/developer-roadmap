# A* Algorithm

The A* (pronounced "A-star") algorithm is a graph traversal and pathfinding algorithm widely used in computer science. It finds the shortest path between a starting node and a goal node by combining the benefits of Dijkstra's algorithm (which guarantees the shortest path) and Greedy Best-First-Search (which uses heuristics for speed). A* uses a heuristic function to estimate the cost from the current node to the goal, making it both complete and optimal when using an admissible heuristic.
