# Island traversal

Island traversal refers to the technique of finding and counting connected components (or "islands") in a grid or graph. The classic "Number of Islands" problem involves counting distinct regions of connected cells in a 2D grid, typically using Depth-First Search (DFS) or Breadth-First Search (BFS). This pattern is fundamental to graph theory and appears frequently in coding interviews, teaching concepts like grid-based graph traversal, connected components, and boundary checking.
