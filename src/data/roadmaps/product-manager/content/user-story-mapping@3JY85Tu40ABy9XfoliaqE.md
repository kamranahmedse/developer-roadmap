# User Story Mapping

User story mapping is a visual technique for organizing user stories into a coherent product backlog that reflects the user's journey through the product. Created by Jeff Patton, it arranges stories along two dimensions: the horizontal axis represents the user's workflow (activities and tasks), while the vertical axis represents priority and detail level. This approach helps teams see the big picture, identify gaps in the backlog, plan releases effectively, and ensure that the product delivers a complete user experience rather than disconnected features. Product Managers use story mapping to facilitate planning sessions and communicate product scope.
