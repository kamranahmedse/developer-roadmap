# Kanban Basics

Kanban is an agile framework that focuses on visualizing work, limiting work in progress, and optimizing flow. Unlike Scrum's fixed sprints, Kanban uses a continuous flow model where work items move through stages on a visual board (typically: To Do → In Progress → Done). Key principles include visualizing the workflow, limiting work in progress (WIP) to prevent overload, managing flow, making policies explicit, and continuously improving. For Product Managers, Kanban provides flexibility to reprioritize as needed while maintaining a clear view of team capacity and work status. It's particularly well-suited for teams with continuous delivery models.
