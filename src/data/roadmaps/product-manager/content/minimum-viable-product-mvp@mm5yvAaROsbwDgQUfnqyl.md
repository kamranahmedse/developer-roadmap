# Minimum Viable Product (MVP)

A Minimum Viable Product (MVP) is the simplest version of a product that delivers enough value to attract early adopters and validate key assumptions. It includes only the core features necessary to solve the primary user problem and gather feedback for future development. The MVP concept, popularized by Eric Ries in The Lean Startup, helps teams avoid building products that nobody wants by testing hypotheses with minimal investment. Product Managers define the MVP by identifying the riskiest assumptions, determining the minimum feature set needed to test them, and establishing success criteria for the validation.
