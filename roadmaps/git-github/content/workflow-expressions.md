# Workflow Expressions

Workflow expressions in GitHub Actions are used to evaluate values, set environment variables, and access contexts in workflow files.

Visit the following resources to learn more:

- [@official@Expressions](https://docs.github.com/en/actions/concepts/workflows-and-actions/expressions)
- [@official@Evaluate expressions in workflows and actions](https://docs.github.com/en/actions/reference/workflows-and-actions/expressions)
