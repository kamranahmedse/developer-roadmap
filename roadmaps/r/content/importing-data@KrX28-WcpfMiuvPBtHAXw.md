# Importing Data

This section covers getting data from outside sources into R, whatever form it originally comes in. Different sources, flat files, spreadsheets, web pages, and APIs, each need a different approach to load correctly.

Visit the following resources to learn more:

- [@article@Importing Data](https://intro2r.com/importing-data.html)
- [@article@Importing Data Files into R](https://libguides.chapman.edu/R/import)
- [@video@How to import data and install packages.](https://www.youtube.com/watch?v=e8B9YU_M5FM)
